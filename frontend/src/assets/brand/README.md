Place the original, unmodified user-provided images here:

- `ganesh-youth-2026.png` (or .jpg, .jpeg, .webp): official square 2026 logo.
- `ganesh-festival.png` (or .jpg, .jpeg, .webp): supporting vertical festival image.

The shared Logo component imports these assets at build time and displays the logo
with object-contain. The supporting image is reserved for the sign-in visual.
Until the originals are available, the interface shows the community name as plain
text and does not substitute or generate a different logo.
